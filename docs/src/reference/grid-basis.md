# Grid and solid-harmonic basis

## `Grid`

`Grid` is re-exported from MRIGeometry.jl and defines the physical Cartesian reconstruction grid used by the encoding operators.

```julia
Grid(...)
```

The physical coordinates in `grid.x`, `grid.y`, and `grid.z` determine the spatial phase generated by the field coefficients. Coordinate units must therefore be consistent with the units of the corresponding first- and higher-order coefficients.

See [Symbols and notation](/theory/symbols) and [Expanded encoding model](/theory/encoding-model) for the coordinate and phase conventions.

## `basisfunc_spha`

```julia
basisfunc_spha(
    x::AbstractVector{T},
    y::AbstractVector{T},
    z::AbstractVector{T},
    terms::AbstractVector{Int},
) where T<:AbstractFloat
```

Evaluates the requested real solid-harmonic basis terms at the supplied coordinates and returns an array of size `(length(x), length(terms))`.

### Arguments

- `x`, `y`, `z`: spatial coordinates of the evaluated voxels.
- `terms`: integer basis indices.

### Returns

- `bfuncOut`: one column per requested basis term.

The current encoding constructors use 9-term and 16-term orderings (through second and third order, respectively). The complete operator ordering is defined in the [solid-harmonic basis table](/theory/encoding-model#solid-harmonic-basis-order).

### Example

```julia
terms = collect(1:9)
bf = basisfunc_spha(grid.x, grid.y, grid.z, terms)
```
