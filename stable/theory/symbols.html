Symbols and notation ​

This page maps the mathematical notation to the arrays used by HighOrderMRI. Use it alongside the encoding model for physical phase conventions and the low-rank derivation for the algorithm. Unless a page explicitly states a local convention, the same symbol has the same meaning throughout the documentation.

The readouts indexed by i encode one unknown image. The shared rSVD notation below distinguishes the completed incremental representation (superscript (0) and rank R0) from the final representation after optional recompression (rank R).

In the implementation, the time-integrated coefficients kℓ,i(t) are stored in kspha. Convert field-camera phase from radians to cycles before supplying it; the encoding constructors do not integrate instantaneous fields or perform this conversion. The physical first-order dot product uses x/y/z; the NFFT uses only axes in I. In 2D, the z term stays in R and is counted once. See the coordinate scope for the Cartesian-grid contract.

D=WHWNonnegative diagonal normal weights, with entries $w

The weighted normal operator is written

AHWHWA.

For real non-negative square-root density weights, WHW=W2. For complex raw weights use WHW, whose diagonal is abs2.(weight).

recon_HOOp applies the raw weights to both the data and A; pass the raw weights once. The lower-level normalOperator(op, weights2) convention instead expects the already squared real nonnegative diagonal entries of D. See reconstruction weights and the weighted-normal API for the relevant call conventions. The data normal excludes any regularization term chosen by the solver.

Low-rank quantities ​

The local rSVD sketch width is Lsk=L+p≤min(Nt,Nv); ℓ is reserved for the solid-harmonic row index. Bi below is HiHQi, the projected adjoint matrix.

Bi=HiHQiProjected adjoint matrixNv×Lsk

The shared projection residual is Zi=V~i−Si−1Ciold, with shape Nv×L. In contrast, Ri is the scalar column count of Si. The local rSVD rotation Zisvd is a separate matrix; the superscript distinguishes it from this residual.

For incremental rSVD construction, a central implementation detail is that, for an earlier profile, the saved coefficient block is generally not the post-hoc projection of V~i onto the completed incremental basis:

C¯i≠(S(0))HV~i.

The incremental shared builder does not retain earlier V~i matrices for reprojection when later profiles expand the basis. Its representation is

Hi≈q^i(0)(S(0))H.

Optional final global recompression maps the completed factors to q^i,S with R≤R0; without it these factors are unchanged. The final residual model and stored temporal rows are

Hi≈q^iSH,qi(j,:)=d0,jicctr,jiNvq^i(j,:).

τ refers to compression of retained local factors. ϵg refers to additional error relative to the already shared representation. Neither is an image-error tolerance. See the algorithm and error derivation.

The single-profile LowRank overload also accepts a coefficient matrix (nTerm,nSam) and a time vector (nSam,). For one profile, concomitant may be (4,nSam).

With basis_layout=:per_readout, q instead has shape (nSam*nDyn,L) and the logical spatial-factor bank has shape (nVox,L*nDyn). Regenerated storage need not materialize this whole bank; see per-readout storage.

Julia column-major vectorization makes samples the fastest-changing index, followed by profiles and then receive channels. For a logical output yjic, its one-based vector index is

j+(i−1)Nt+(c−1)NtNro.

Use vec(image) for the full-grid input and vec(data) for output shaped (nSam,nDyn,nCha); masked-out image values do not contribute to the signal.
