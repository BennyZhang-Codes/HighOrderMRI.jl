On this page

API reference ​

The API reference is organized as a set of short pages, following the same separation used by established Julia MRI documentation: each page focuses on one public type, constructor, or closely related function family. Scientific derivations and validation requirements remain in the Theory and Guide sections.

Encoding model and operators ​

  • Grid and basisfunc_spha: physical reconstruction grid and real solid-harmonic basis evaluation.
  • HighOrderOp: array-based explicit field-aware encoding.
  • HighOrderKernelOp: fused explicit CUDA encoding with optional multi-GPU voxel decomposition.
  • HighOrderLowRankOp: low-rank residual-phase representation with an incremental shared spatial basis.

Reconstruction ​

  • recon_HOOp: iterative reconstruction wrapper.
  • samplingDensity: square-root sampling-density weights for non-Cartesian reconstruction.

Coil compression ​

  • CoilCompressionTransform: fitted linear receive-coil transform.
  • estimate_noise_covariance: complex receive-noise covariance estimation.
  • noise_prewhitening_scale_factor: dwell-time / receiver-bandwidth scale factor.
  • fit_coil_compression: fit global SVD or noise-whitened SVD compression.
  • apply_coil_compression: apply a fitted transform along a selected coil dimension.
  • compress_coils: fit one transform and apply it consistently to data and CSM.

Field prediction and synchronization ​

  • GIRFModel: typed frequency-domain GIRF representation.
  • apply_girf: predict realized field channels from nominal physical gradients.
  • InterpTrajTime: interpolate field/trajectory coefficients to requested ADC times.
  • FindDelay: single-acquisition model-based field/data synchronization.
  • FindDelay_multishot: shared-delay estimation for multi-shot data.

Metrics and utilities ​

  • Reconstruction metrics: raw and aligned complex NRMSE, magnitude NRMSE, SSIM, and compatibility helpers.
  • Array and signal utilities: CPU/GPU conversion, trajectory-gradient conversion, resizing, cropping, and factor helpers.
  • Plotting helpers: common visualization functions.
  • Resource lifecycle: explicit cleanup and safe replacement of large low-rank operators.

Reference vs. methods

Use these pages to check calling conventions and returned objects. Use Symbols and notation, the expanded encoding model, low-rank shared subspace, and the relevant Guide page when interpreting units, phase conventions, approximation parameters, or validation requirements.
